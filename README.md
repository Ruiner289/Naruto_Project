# 부대 행동 메뉴 전술 프로토타입

기존 Godot 4.x + GDScript 프로젝트를 이어서 수정했습니다. Godot 4.5.1에서 검증했습니다. 이 저장소를 내려받거나 clone한 뒤 루트의 project.godot를 Godot로 가져와 F5로 실행합니다. 기존 NinjaFormation.zip 배포본은 압축을 풀고 NinjaFormation/project.godot를 가져옵니다. 기존 user://squad.json이 있으면 주력 부대를 그대로 읽고, 없을 때만 임시 편성을 준비합니다.

## 플레이

20×14 전장에 아군 4개, 적군 4개 부대가 있습니다. 아군은 서쪽, 적군은 동쪽의 여러 행에 분산되어 시작합니다. 적이 멀리 있으므로 이동하거나 턴을 진행하여 접촉합니다.

- 부대 좌클릭: 부대 옆 행동 메뉴를 엽니다. 아군은 ‘이동 / 공격 / 정보 / 대기 / 취소’를 사용합니다. 공격은 현재 위치에서 닿는 적이 있을 때만 표시합니다. 같은 부대를 다시 눌러도 진형 창을 열지 않습니다. 적과 행동을 완료한 아군의 진형도 ‘정보’ 버튼으로 확인합니다.
- 이동: 아군 선택 → ‘이동’ → 청록색의 빈 이동 후보 클릭. 공격: 아군 선택 → ‘공격’ → 빨간 공격 가능 적 타일 클릭 → 전투 시작 확인. 제자리 공격도 같은 순서입니다. 이동 버튼을 누르기 전에는 이동하지 않고, 처음 아군 선택 시 청록 이동 범위와 빨강 예상 공격 범위를 표시합니다. 이동 모드는 청록 범위만 표시하고, 이동 후에는 공격 버튼을 누르기 전까지 공격 색을 표시하지 않습니다.
- 진형 확인은 읽기 전용입니다. 3×3+반칸 배치, 부대장, 현재 HP, 병종을 표시합니다. 우클릭/Esc/닫기로 닫으면 선택이 유지됩니다. 다음 취소는 미확정 이동이 있으면 출발 위치로 되돌리고, 없으면 선택을 해제합니다.
- 적 선택은 다음 행동의 전체 이동력 기준 범위와 ‘정보 / 취소’ 메뉴를 보여줍니다. ‘정보’로 진형을 엽니다. 공격 대상 선택 중 적 클릭은 전투 확인창으로 이어지며 정보 확인보다 우선합니다.
- 청록: 지형/점유를 반영한 실제 이동 범위. 빨강: 최초 부대 선택의 이동 후 예상 공격 범위, 공격 버튼 선택 시에는 현재 위치에서 실제 공격 가능한 적 칸만 표시. 노랑: 경로와 누적 비용.
- 우클릭/Esc: 선택·미확정 공격·드래그 취소. 공격/대기를 확정하기 전 이동은 출발 위치로 되돌리고 다시 이동할 수 있습니다. 공격 확인창이 열려 있으면 먼저 창만 닫고, 다시 취소하면 이동을 되돌립니다. 확정 공격/대기와 캐릭터 배치는 되돌리지 않습니다.
- 이동 후 부대 옆에 행동 메뉴가 자동으로 뜹니다. 현재 위치에서 공격 가능한 적이 있으면 ‘공격’이 표시되며, ‘공격 → 적 선택 → 전투 확인’으로 진행합니다. ‘대기’는 행동 확정, ‘취소’/우클릭/Esc는 출발 위치 복귀입니다. 이동/공격 대상 선택 중 취소는 먼저 메뉴로 돌아갑니다. 이동 전에도 부대 클릭만으로 메뉴가 열립니다. ‘대기’를 누르면 제자리에서 행동을 마칩니다. Space 또는 ‘행동 메뉴 열기’로 메뉴를 다시 열 수 있습니다.
- 이동 후 공격/대기가 가능합니다. 이동을 취소하면 출발 위치에서 다시 이동을 선택할 수 있습니다. 다른 아군을 선택하면 이전 미확정 이동은 취소됩니다. 공격 확인/대기/턴 종료 시 이동이 확정되고, 공격/대기 후에는 다시 행동하지 못합니다.
- ‘턴 종료’: 남은 아군의 행동을 대기로 처리하고 적 턴으로 넘어갑니다. 모든 아군이 행동할 때까지 기다릴 필요가 없습니다.
- 적 턴: 적들이 ID 순으로 이동·공격·대기합니다. 플레이어 전술 입력과 턴 종료는 잠깁니다.
- 적 전투도 같은 자동전투 화면을 사용합니다. 공격을 건 진영의 공격 병종이 먼저 행동하고 살아 있는 방어측이 반격합니다. 양측 공격이 끝난 뒤 공격측 힐러 → 방어측 힐러 순서로 치료합니다. 화면 상단에 현재 진영과 병종 단계를 표시합니다. 결과에서 ‘헥스 전장으로 복귀’를 누르면 아직 행동하지 않은 적부터 이어집니다. 1x/2x/즉시 결과는 사용할 수 있습니다.
- 모든 살아 있는 적의 행동 후 다음 아군 턴으로 넘어가며 턴 번호가 증가합니다. 아군의 이동/행동 상태만 초기화하고 HP는 유지합니다.

전멸한 부대는 공격측·방어측·진영에 관계없이 전장에서 제거되며 그 타일은 빈칸이 됩니다. 살아남은 공격측은 공격했던 위치와 HP·행동 상태를 유지합니다. 턴 시작 위치로 돌아가거나 쓰러뜨린 부대의 타일로 추가 이동하지 않습니다.

진형 안의 캐릭터가 전투불능이 되면 그 교전의 진행/결과 화면에서만 회색 전투불능 상태를 표시합니다. 다음 교전과 진형 확인에서는 해당 캐릭터를 숨깁니다. 살아남은 캐릭터의 기존 배치와 반칸 좌표는 유지하며, 생존 인원 수를 표시합니다.

## 아군 통과와 ZOC

같은 진영 부대가 있는 타일은 통과할 수 있지만 도착지로 사용할 수 없습니다. 상대 진영 부대가 있는 타일은 진입·통과할 수 없습니다. 지형 비용과 통행 제한은 그대로 적용합니다.

살아 있는 적대 부대의 인접 6칸은 ZOC입니다. 그 칸에 진입하면 남은 이동력이 있어도 이동이 끝나며, 현재 위치에서 공격 또는 대기는 가능합니다. 이미 ZOC 안에서 시작한 부대는 밖으로 나갈 수 있지만 다른 ZOC 칸에 진입하면 멈춥니다. 이동 가능한 ZOC 칸은 주황 테두리로 표시합니다. 아군 타일이 적 ZOC 안에 있으면 그 칸을 통과해 더 이동할 수 없습니다. 전멸한 부대는 점유와 ZOC를 남기지 않습니다.

플레이어 범위·경로·실제 이동과 적 AI에 같은 규칙을 적용합니다. 적 AI도 같은 진영을 통과하며 이동력이 끝나는 타일에 아군이 있으면 그 앞의 빈칸에 멈춥니다.

## 전장 보기

기본 화면은 전체 20×14 전장을 한눈에 보여줍니다. 오른쪽 정보창은 도움말 버튼으로 열고 닫습니다. ‘확대 보기’를 선택하면 전장 표시 영역의 가장자리 28픽셀 안에 커서를 두어 해당 방향으로 초당 480픽셀 이동할 수 있습니다. 모서리에서는 대각선으로 이동하며 맵 경계에서 멈춥니다. 커서를 중앙이나 옆 정보창으로 옮기면 정지합니다. 휠로 전장을 이동하지 않습니다. WASD 또는 방향키도 사용할 수 있습니다. 화면 밖 부대도 실제 헥스 좌표를 유지하며 적 이동 시작 시 해당 적을 화면으로 가져옵니다. 맵 스크롤 위치는 전투 씬을 거쳐도 유지합니다. ‘전체 전장’으로 돌아가면 다시 화면에 맞춰 축소합니다. F11 또는 ‘전체화면 F11’ 버튼으로 전체화면/창 모드를 전환합니다.

커서 아래 헥스에 노란 모서리 표식을 표시합니다. 카메라가 이동해도 현재 커서 아래 헥스를 다시 판정합니다. 미확정 전투/진형 창, 확정 이동, 적 턴에는 커서 자동 이동을 멈춥니다.

헥스에 마우스를 올리면 지형 이름, 통행 여부, 이동 비용, q/r 좌표를 볼 수 있습니다. 경로 위 숫자는 누적 비용입니다. 부대 정보에는 이름/ID/진영/부대장/인원/HP/이동력/행동 상태를 표시합니다.

## 지형

| 지형 | 이동 비용 | 표시 |
|---|---:|---|
| 평지 | 1 | 녹회색 · |
| 도로 | 1 | 갈색 = |
| 숲 | 2 | 짙은 녹색 ♠ |
| 늪 | 3 | 올리브 ~ |
| 산 | 3 | 보라회색 ▲ |
| 물 | 통행 불가 | 파랑 ≈ |
| 장애물 | 통행 불가 | 짙은 회색 × |

북쪽 2행과 남쪽 11행은 저비용 길입니다. 중앙은 숲/늪/산과 봉쇄 구간, 6행 통로가 있으며 동남쪽에는 물이 있습니다. 무작위가 아닌 고정 테스트 전장입니다. 아군과 적은 같은 Dijkstra/지형 비용/점유/공격 규칙을 사용합니다.

이동력은 임시 4, 전장 공격 거리는 1헥스입니다. 지형 비용의 합을 소비하므로 항상 네 칸 이동할 수 있는 것은 아닙니다. 테스트 HP/ATK/병종 배정은 최종 밸런스가 아닙니다.

## 거점

아군 본진은 서쪽 (offset 1,7), 중립 전초는 중앙 (10,6), 적 본진은 동쪽 (18,7)에 있습니다. 파란/회색/빨간 깃발로 표시합니다. 위치·이름·종류·소유자 데이터만 있으며 점령·회복·보급·생산·수입·거점 승리 조건은 없습니다.

## 유지된 전투와 제한

기존 SquadData/NinjaData/FormationSlot/JSON/씬을 재사용했습니다. 기본 3×3+반칸6개, 최대9명과 진영별 6단계 단일 공방, 대상 사전 예약/전투불능 공격 대상 재선택/사망 행동 취소/공격 후 Healer 치료를 유지합니다. 원거리 병종도 전장 공격 거리는 현재 1입니다.

전체 전장/턴 저장, 줌, 복잡한 AI, 인술, 차크라, 성장, 장비, 전략/국가 운영은 없습니다. AI는 현재 공격 가능→이동 후 공격 가능→최소 접근 경로 비용 순으로 선택하는 단순 모델입니다. 접근할 수 있는 목표가 없으면 대기합니다. 첫 전투 이후 편성은 잠깁니다. ‘모든 부대 회복’은 별도 개발 디버그 버튼입니다.

## 4개 팀 재배치 업데이트

아스마반(아스마·시카마루·이노·쵸지), 쿠레나이반(쿠레나이·키바·히나타·시노), 가이반(가이·리·네지·텐텐)의 모든 기본 스프라이트를 연결했습니다. 누락된 가이반 4종은 GitHub 원본 시트에서 87프레임을 추출했습니다. 전체 22프로필/509프레임이며, 대기·이동·일반 공격·피격·전투불능 동작과 텐텐의 원거리 투척을 제공합니다. 인술·캐릭터 고유 스킬은 아직 구현하지 않습니다.

전장을 아군 4부대(카카시반 포함)와 적군 4부대로 변경했습니다. 각 부대는 4명입니다. 이번 버전 첫 실행은 기존 주력 편성을 바이트 그대로 백업한 뒤 카카시반을 적용하고, 이후 편성 수정은 보존합니다. 스프라이트 개발 미리보기 E 버튼에서 가이반 전투를 확인할 수 있습니다.

[FOUR_TEAMS_REPORT.md](FOUR_TEAMS_REPORT.md)에 팀별 확인 결과, 추가 프레임, 배치 및 22개 테스트 결과가 있습니다.

## 우클릭 전장 메뉴

선택/미확정 조작이 없는 상태에서 화면 어디든 우클릭하면 커서 옆에 ‘턴 종료 / 부대 보기 / 도움말 / 닫기’ 메뉴가 열립니다. 선택·이동/공격 대상·확인창이 있으면 우클릭은 기존 취소를 먼저 처리하고, 이후 빈 상태에서 우클릭하면 전장 메뉴를 엽니다. 부대 보기는 살아 있는 아군/적군 목록이며 항목을 누르면 그 부대 진형을 확인합니다.

상단 턴 종료 버튼의 입력 순서도 수정했습니다. [CONTEXT_MENU_REPORT.md](CONTEXT_MENU_REPORT.md)에 29개 테스트와 실제 버튼 클릭 결과가 있습니다.
